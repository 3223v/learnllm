以下为你设计了10个由浅入深的 PyTorch Lab，覆盖从张量操作到复杂项目的完整学习路径。每个 Lab 均明确了目标、核心实现点与验收标准，你只需按顺序完成代码实现即可系统掌握 PyTorch。

---

### Lab 1：张量基础操作

**目标**：熟悉 `torch.Tensor` 的创建、属性、运算与设备管理。

**你需要实现**：
- 用多种方式创建张量（列表、全0、全1、随机、序列、像其他张量）
- 查看张量的 `shape`、`dtype`、`device`
- 张量算术运算、矩阵乘法、广播机制
- 改变形状 `reshape`/`view`，拼接 `cat`，索引与切片
- 检测 GPU 可用性，将张量在 CPU 与 GPU 间移动

**验收**：能写出不查阅文档即可完成张量运算的脚本，并打印关键属性。

---

### Lab 2：自动求导与手动梯度下降

**目标**：理解自动微分机制，实现最简单的线性模型训练。

**你需要实现**：
- 创建带 `requires_grad=True` 的张量，使用 `backward()` 计算梯度
- 演示梯度累积与 `grad.zero_()` 的作用
- 禁止梯度计算的场景：`torch.no_grad()` 与 `detach()`
- **任务**：用 `y = 3x + 2 + 噪声` 生成数据，初始化参数 `w`，`b` 为可求导张量
- 手写梯度下降循环：前向计算 MSE Loss → `backward()` → 手动更新参数 → 清零梯度
- 可视化损失下降与拟合直线

**验收**：损失稳定趋近于0，最终 `w≈3, b≈2`。

---

### Lab 3：模块化构建网络

**目标**：掌握 `nn.Module`、`nn.Linear`、激活函数与前向传播。

**你需要实现**：
- 继承 `nn.Module` 自定义一个全连接网络（如 1 隐藏层，激活 ReLU）
- 使用 `nn.Sequential` 快速搭建同样结构的网络
- 打印模型结构，查看所有可学习参数（`model.parameters()`）
- 用随机输入测试前向传播的形状
- 将模型移到 GPU（如可用）

**验收**：能灵活使用两种方式搭建网络，并理解参数的注册与管理。

---

### Lab 4：数据加载与预处理

**目标**：学会 `Dataset`、`DataLoader` 及 `torchvision.transforms`。

**你需要实现**：
- 继承 `Dataset` 实现一个简单的自定义数据集（如从内存数组生成）
- 使用 `torchvision.datasets.MNIST` 下载并加载数据
- 编写 `transform`：转 Tensor、归一化；可选添加随机旋转等增强
- 创建 `DataLoader`，测试批数据形状、打乱、多进程加载
- 遍历一个 epoch 并显示一批图像（用 matplotlib）

**验收**：能正确构建任意数据集的数据加载流水线。

---

### Lab 5：完整训练循环——MNIST 分类

**目标**：整合已学知识，写出规范的训练、验证、保存脚本。

**你需要实现**：
- 使用 Lab3 的全连接网络（或稍加深）在 MNIST 上分类
- 交叉熵损失、SGD 或 Adam 优化器
- 训练循环：epoch 循环，每 batch 前向、损失、反向、优化
- 验证循环：评估准确率，`model.eval()` + `torch.no_grad()`
- 保存最佳模型权重 `torch.save`
- 使用学习率调度器 `StepLR`
- 绘制训练/验证 loss 与 accuracy 曲线

**验收**：测试准确率 ≥ 97%，保存的模型可重新加载并复现结果。

---

### Lab 6：卷积神经网络——CIFAR-10 分类

**目标**：掌握 CNN 构建与 GPU 训练。

**你需要实现**：
- 自定义 CNN（若干 `Conv2d` + `ReLU` + `MaxPool2d` + 全连接）
- 在 CIFAR-10 上训练，使用 GPU 加速
- 数据增强：随机水平翻转、随机裁剪
- 添加 Dropout 或 BatchNorm 提升泛化
- 实现早停（Early Stopping）基于验证损失

**验收**：CIFAR-10 测试准确率 ≥ 75%，整个训练在 GPU 上运行不报错。

---

### Lab 7：迁移学习与微调

**目标**：使用预训练模型快速获得高精度。

**你需要实现**：
- 加载预训练的 ResNet-18（`torchvision.models`）
- 冻结卷积层，替换最后的全连接层适配 CIFAR-10
- 使用较小的学习率微调整个网络
- 对比冻结特征提取器与全微调的效果差异
- 尝试不同的学习率策略（如对不同层设置不同学习率）

**验收**：测试准确率 ≥ 90%，并能解释冻结与微调的适用场景。

---

### Lab 8：循环神经网络——文本生成

**目标**：掌握 RNN/LSTM 的用法以及序列建模流程。

**你需要实现**：
- 选择一个文本（如莎士比亚作品或尼采文集），进行字符级编码
- 构建滑动窗口数据集（输入序列 vs 下一字符）
- 定义 LSTM 模型：Embedding → LSTM → Linear
- 训练并使用温度采样生成文本
- 展示训练过程中生成文本质量的变化

**验收**：可生成看起来像原文风格的长文本，损失明显下降。

---

### Lab 9：高级特性实战

**目标**：掌握自定义数据集、自定义损失、混合精度与可视化。

**你需要实现**：
- 从文件夹读取图片构建自定义 `Dataset`（如猫狗分类）
- 实现一个 Focal Loss 替代交叉熵处理样本不平衡
- 开启自动混合精度训练（`torch.cuda.amp`），比较速度与显存
- 使用 `TensorBoard` 记录标量、图片、模型图、嵌入
- 封装一个 `Trainer` 类，将训练、验证、日志、保存整合

**验收**：混合精度训练加速明显，TensorBoard 可展示丰富日志，`Trainer` 复用性强。

---

### Lab 10：综合项目——图像分割（U-Net）

**目标**：独立完成一个完整、较复杂的视觉任务，串联所有 PyTorch 技能。

**你需要实现**：
- 从零搭建 U-Net 结构（编码器-解码器、跳跃连接）
- 使用 CamVid 或简易合成分割数据进行训练
- 实现 Dice Loss 与像素级交叉熵损失的组合
- 训练中动态可视化预测掩膜（TensorBoard 或 matplotlib）
- 实现推理脚本，对单张图片输出分割结果并叠加显示
- 尝试 ONNX 导出或 TorchScript 转换以准备部署

**验收**：在验证集上 IoU 达到合理水平，代码结构清晰，模块化程度高，能保存、加载和推理。
